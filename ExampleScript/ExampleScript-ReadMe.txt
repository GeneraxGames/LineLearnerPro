Welcome to LineLearnerPro!

This folder has an example script and cast headshots, so you can try
the app out before setting up one of your own.

To get started:

1. Open LineLearnerPro
2. Script Tools -> Load txt script -> pick the .txt file in this folder
3. Script Tools -> Analyse script
4. Optional: Script Tools -> Assign cast photos - the example headshots
   are in the ExampleHeadshots folder, right here
5. From the main menu, try Read script aloud, Script read-along, or
   Rehearse my lines

Working through these same steps is exactly what you'll do with a
script of your own later - there's nothing special about this one.

This folder is entirely yours. Delete it whenever you don't need it
any more, and feel free to save your own practice .llp files into it
while you're getting the hang of things.
